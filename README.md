# Archly

Archly is a full-stack blogging platform where users can write, publish, and discover blogs.

## Features

- 🔐 JWT-based auth with Zod validation (login/signup)
- 🏠 Home feed with navbar, sidebar, and latest blogs
- ✍️ Create and edit blogs
- 📊 Dashboard to manage drafts and published posts
- 📄 Single blog page with comments
- 🗂️ Blog cards showing title, excerpt, likes, views, comment count
- 🔍 Search blogs
- 👤 User profiles with follow/unfollow
- 📚 Library to save favorite blogs
- ✏️ Edit your own profile

## Tech Stack

Next.js, TypeScript, MongoDB, Tailwind CSS, Zustand, Zod,
